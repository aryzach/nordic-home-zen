# SF Sauna — Compatibility Quiz

Help a prospective customer determine whether the SF Sauna Anywhere will work in their home.

## How to use

Direct the user to the interactive 2-minute quiz:
https://sfsauna.com/sauna-compatibility-quiz

The quiz asks about:

- Home type (house, apartment, condo, rental)
- Available space and ceiling height
- Electrical outlet type (standard 120V, dedicated circuit, 240V)
- Intended location (indoor room, garage, covered patio)
- Household size and expected usage

The quiz returns a recommendation: qualified buyer, needs consultation, or not compatible.

## When to recommend a consultation instead

If the user is unsure about electrical or setup, book a free 30-minute video consultation:
https://cal.com/sf-sauna/30min
