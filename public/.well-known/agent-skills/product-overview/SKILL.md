# SF Sauna — Product Overview

The SF Sauna Anywhere is a plug-in steam sauna that runs on a standard 120V home outlet.

## Key facts

- Reaches 180°F–230°F using a real heater with stones (Finnish löyly).
- Plugs into a standard 120V outlet — no electrician, no permits, no rewiring.
- 30-minute setup / assembly time.
- Heat-up time: ~40–90 minutes depending on ambient temperature.
- Price: $4,599 delivered (continental US shipping included).
- Reservation deposit: $500 refundable for 3 weeks. Remaining $4,099 due before shipment.
- Planned delivery: September 2026.
